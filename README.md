# 🥐 Булочка учит Deutsch

Персональная платформа для изучения немецкого языка — от A1 до B1.

Сделано с ❤️ Матвеем для Булочки.

## Как запустить

Открыть `index.html` в браузере или захостить на GitHub Pages.

## GitHub Pages

1. Создай репозиторий на GitHub
2. Загрузи все файлы
3. Settings → Pages → Source: `main` branch, `/root`
4. Сайт будет доступен по адресу `https://USERNAME.github.io/REPO-NAME`
