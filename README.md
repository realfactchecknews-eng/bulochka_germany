# 🥐 Булочка учит Deutsch

Персональная платформа для изучения немецкого языка — от **A1 до B1**.
Сделано с ❤️ Матвеем для Булочки (подготовка к поступлению в австрийский вуз).

---

## ✨ Возможности

- **📖 Курс по грамматике (по темам, без деления на уровни)** — последовательное
  прохождение грамматики (от существительного/артикля → падежи → местоимения →
  глаголы → прилагательные → предлоги → синтаксис → продвинутое). Структура и
  глубина опираются на грамматику Тагиля и Die Gelbe (контент — оригинальный,
  не копия учебников). Каждая тема: **первый блок — основа**, затем блоки с
  **тонкостями и частыми ошибками**.
- **🧱 Уроки в формате «шагов» (как на Stepik)** — тема разбита на квадратики-шаги:
  📘 основная теория → 📖 тонкости → ❓ выбор → ✎ вписать → 🔤 перевод → 🎧 аудио →
  📑 чтение → ✍️ письмо. Идёшь по шагам, полоска прогресса сверху (`lesson.js`).
- **🎯 Задания разных типов** — multiple-choice (с пояснением), вписать ответ,
  перевод (с менее банальной лексикой), **чтение** (текст + вопросы),
  **свободное письмо с ИИ-проверкой**, **аудирование** (озвучка через браузер).
  Немецкие слова в теории кликабельны → перевод + добавление в карточки.
- **🎬 Видео-уроки** — по YouTube (Nicos Weg, @deutschmityehor).
- **✍️ Письменные задания** — задания с **ИИ-проверкой** каждой ошибки,
  персональный урок по запросу, загрузка **фото рукописи** (vision-проверка).
- **📚 Грамматика** — справочник с таблицами и правилами.
- **🃏 Карточки (Anki)** — 12 крупных тематических колод + «🌟 Мои слова»
  (свои слова из книг/уроков). Интервальные повторения, **прогресс привязан к
  слову** (не сбивается при пересортировке колод), **синхронизация с облаком**.
- **📖 Читалка книг** — Emil und die Detektive (A2), Bridget Jones (B1).
  Клик по слову → ИИ-перевод → можно добавить слово в карточки.
- **💬 Чат «Фрау Анна»** — ИИ-ассистент на всех страницах.
- **👥 Мультиюзер** — каждый со своим аккаунтом и прогрессом. Тема Марго
  (`bulochka`) — персональная; остальные видят нейтральный простой дизайн
  (`js/theme.js`). Регистрация новых аккаунтов прямо на странице входа.

---

## 🛠️ Технологии

- Статический сайт (GitHub Pages), vanilla HTML/CSS/JS — без сборки.
- **Firebase** Auth (Email/Password) + Firestore (через CDN, ES-модули).
- **OpenRouter** API (`openai/gpt-4o-mini`) для ИИ-проверки, переводов, чата.

---

## 📁 Структура

```
index.html        — главная (курс по темам + быстрый доступ к разделам)
lesson.html       — страница урока (шаговый интерфейс)
writing.html      — письменные задания с ИИ-проверкой
grammar.html      — справочник грамматики
anki.html         — карточки + интервальные повторения
books.html        — читалка с переводом по клику
whats-new.html    — апдейты + форма обратной связи (только для Марго)
login.html        — вход (+ регистрация новых аккаунтов)
css/style.css
js/
  firebase-config.js — конфиг Firebase + USER_MAP (логин→email)
  data.js            — последовательность тем курса (без уровней)
  lessons-content.js — контент уроков (теория-блоки + упражнения)
  lesson.js          — шаговый движок урока (Stepik-style)
  goethe-data.js     — словарь Goethe B1 (исходные колоды-«сырьё»)
  word-lookup.js     — кликабельные слова → перевод → добавить в Anki
  theme.js           — тема оформления (personal=Марго / generic=гости)
  sync.js            — Firebase Auth + синхронизация с Firestore
  app.js / chat-widget.js / books-data.js
```

**Обратная связь от Марго** копится в Firestore-коллекции `feedback`
(страница `whats-new.html`). Гости берут отдельный ключ ИИ из
`config/openrouter_guest`.

## 🚀 Запуск

Открыть `index.html` в браузере, либо хостинг на **GitHub Pages**:
Settings → Pages → Source: `main` branch, `/root`.
Сайт: `https://realfactchecknews-eng.github.io/bulochka_germany/`

---

## 🔒 Безопасность

- Репозиторий **публичный**. Никаких паролей и ключей в коде/README.
- Ключ OpenRouter хранится **только в Firestore** (`config/openrouter` → `key`)
  и читается приложением в рантайме. **Никогда не коммитить ключ.**
