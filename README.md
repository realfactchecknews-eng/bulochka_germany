# 🥐 Булочка учит Deutsch

Персональная платформа для изучения немецкого языка — от **A1 до B1**.
Сделано с ❤️ Матвеем для Булочки (подготовка к поступлению в австрийский вуз).

---

## ✨ Возможности

- **📖 Курс A1→B1** — 40+ уроков по «Die Gelbe» + **видео-уроки** по YouTube
  (Nicos Weg, @deutschmityehor). Теория, таблицы, упражнения (выбор / вписать /
  перевод). Немецкие слова в теории кликабельны → перевод + добавление в карточки.
- **✍️ Письменные задания** — задания A1/A2/B1 с **ИИ-проверкой** каждой ошибки,
  персональный урок по запросу, загрузка **фото рукописи** (vision-проверка).
- **📚 Грамматика** — справочник по разделам A1/A2/B1 с таблицами и правилами.
- **🃏 Карточки (Anki)** — 12 крупных тематических колод + «🌟 Мои слова»
  (свои слова из книг/уроков). Интервальные повторения, **прогресс привязан к
  слову** (не сбивается при пересортировке колод), **синхронизация с облаком**.
- **📖 Читалка книг** — Emil und die Detektive (A2), Bridget Jones (B1).
  Клик по слову → ИИ-перевод → можно добавить слово в карточки.
- **💬 Чат «Фрау Анна»** — ИИ-ассистент на всех страницах.

---

## 🛠️ Технологии

- Статический сайт (GitHub Pages), vanilla HTML/CSS/JS — без сборки.
- **Firebase** Auth (Email/Password) + Firestore (через CDN, ES-модули).
- **OpenRouter** API (`openai/gpt-4o-mini`) для ИИ-проверки, переводов, чата.

---

## 📁 Структура

```
index.html        — главная (курс + быстрый доступ к разделам)
lesson.html       — страница урока
writing.html      — письменные задания с ИИ-проверкой
grammar.html      — справочник грамматики
anki.html         — карточки + интервальные повторения
books.html        — читалка с переводом по клику
login.html        — вход
css/style.css
js/
  firebase-config.js — конфиг Firebase + USER_MAP (логин→email)
  data.js            — модули и список уроков курса
  lessons-content.js — контент уроков (теория + упражнения)
  lesson.js          — логика урока
  goethe-data.js     — словарь Goethe B1 (исходные колоды-«сырьё»)
  word-lookup.js     — кликабельные слова → перевод → добавить в Anki
  sync.js            — Firebase Auth + синхронизация с Firestore
  app.js / chat-widget.js / books-data.js
```

## 🚀 Запуск

Открыть `index.html` в браузере, либо хостинг на **GitHub Pages**:
Settings → Pages → Source: `main` branch, `/root`.
Сайт: `https://realfactchecknews-eng.github.io/bulochka_germany/`

---

## 🔒 Безопасность

- Репозиторий **публичный**. Никаких паролей и ключей в коде/README.
- Ключ OpenRouter хранится **только в Firestore** (`config/openrouter` → `key`)
  и читается приложением в рантайме. **Никогда не коммитить ключ.**
